Privacy policy — taroball-assistant

Last updated: 2026-10-16

What the app does

taroball-assistant is a private tool used only by its owner, on the owner's own computer. It (1) sends report emails from the owner's bot Gmail account to the owner, and (2) sorts the owner's personal Gmail inbox: it applies labels, archives advertising and scam email, and saves booking confirmations to the owner's Google Drive, and (3) helps the owner reorganize their own Google Drive into a tidier folder structure.

Google user data

  • gmail.send (bot account only): to send report emails.
  • gmail.modify (owner's personal account): to read incoming messages' headers and text in order to classify them, and to add labels and archive. The app never sends, forwards, trashes or deletes email from this account.
  • drive.file: to create files (booking confirmations) in the owner's Drive. The app can see only the files it created itself, not any other Drive content.
  • drive.metadata.readonly (owner's personal account): to list the names, folders, types, sizes, dates and sharing status of the owner's Drive files, in order to propose a tidier folder structure. File contents are not read.
  • drive (requested separately, only after the owner approves a proposed move plan): to move the owner's files into the approved folders. The app never deletes, trashes, or changes the sharing of any file, and logs every move so it can be undone.
  • AI classification: for each new message, the sender, subject, authentication results and up to the first 2 KB of its text are sent to Anthropic's Claude, under the owner's own Claude account, solely to decide which label applies. Attachments are never sent. For Drive organizing, file and folder names and paths (never file contents) are sent the same way to suggest where each file belongs. Anthropic's handling of that data is governed by Anthropic's privacy policy.
  • Storage: OAuth refresh tokens are kept only in the owner's local macOS Keychain. A local log of classification decisions (sender, subject, label, reason) and a local index of Drive file metadata stay on the owner's computer. No data is stored on any server run by this app.
  • Sharing: apart from the AI classification step above, no Google user data is shared with, sold to, or transferred to any third party. Google user data is not used to train AI models.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
