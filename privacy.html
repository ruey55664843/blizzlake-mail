Privacy policy — taroball-assistant

Last updated: 2026-10-16

What the app does

taroball-assistant is a private tool used only by its owner, on the owner's own computer. It (1) sends report emails from the owner's bot Gmail account to the owner, and (2) sorts the owner's personal Gmail inbox: it applies labels, archives advertising and scam email, and saves travel booking confirmations to the owner's Google Drive.

Google user data

  • gmail.send (bot account only): to send report emails.
  • gmail.modify (owner's personal account): to read incoming messages' headers and text in order to classify them, and to add labels and archive. The app never sends, forwards, trashes or deletes email from this account.
  • drive.file: to create files (booking confirmations) in the owner's Drive. The app can see only the files it created itself, not any other Drive content.
  • AI classification: for each new message, the sender, subject, authentication results and up to the first 2 KB of its text are sent to Anthropic's Claude, under the owner's own Claude account, solely to decide which label applies. Attachments are never sent. Anthropic's handling of that data is governed by Anthropic's privacy policy.
  • Storage: OAuth refresh tokens are kept only in the owner's local macOS Keychain. A local log of classification decisions (sender, subject, label, reason) stays on the owner's computer. No data is stored on any server run by this app.
  • Sharing: apart from the AI classification step above, no Google user data is shared with, sold to, or transferred to any third party. Google user data is not used to train AI models.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
