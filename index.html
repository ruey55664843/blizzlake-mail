blizzlake-mail

blizzlake-mail is a private, single-user tool. It sends automated report emails from the owner's own Gmail account (blizzlake2025@gmail.com) to the owner. It is not offered to the public and has no other users.

It uses the Gmail API with one permission only: gmail.send (send email). It cannot read, search, modify, or delete any email.
